Project Name: FitTrack - Simple Exercise Guide

Description:
A simple fitness website that shows different exercises with instructions.
Users can browse exercises by category and see how to do each exercise.

Data I will store:
- Exercises: name, category, difficulty, description, image, duration
- Categories: strength, cardio, flexibility

Main Features:
- View all exercises
- Filter exercises by category
- Simple and clean design
- Easy to follow instructionsFITNESS APP IDEAS - IMPLEMENTED ✅

1. Core Feature: Personal Trainer Questionnaire
   - Ask goal (weight loss, muscle gain, general fitness)
   - Ask fitness level (beginner, intermediate, advanced)
   - Ask days per week available (2-5 days)

2. Generate Weekly Workout Plan
   - Dynamic plan based on user answers
   - Daily exercises with sets/reps
   - Basic instructions and form tips
   - Rest day suggestions

3. Clean & Beginner-Friendly Interface
   - Simple questionnaire flow
   - Visual day cards
   - Clear exercise instructions

4. Progress Tracking (Optional)
   - Workout log button
   - Streak counter
   - LocalStorage persistence

5. Motivation System
   - Dynamic encouragement messages
   - Streak-based rewards (in messages)
   - Consistency reminders

6. Future Ideas:
   - Add video demonstrations
   - Export plan to PDF
   - User accounts
   - Advanced analytics
